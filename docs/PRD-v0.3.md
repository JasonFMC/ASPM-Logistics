# ASPM YARD 产品需求文档

- **项目名**：ASPM YARD
- **文档版本**：v0.4（按当前已实现行为更新，取代 2026-03-21 的 v0.3 正文）
- **用途**：场外货物位置可视化记录与查找。位置以上传的底图为准，不使用 GPS
- **目标用户**：仓库工人、文员、主管
- **部署**：澳洲优先；移动优先；免费栈优先（Supabase Sydney + GitHub Pages）
- **日期**：2026-09-28

---

## 1. 背景

公司位于澳洲，场外堆场大。TradeWindow 管库存数量，位置长期靠 Google Sheet「画格子」，导致查找难、外人看不懂、更新不及时、照片分散。

ASPM YARD 成为场外位置的记录工具：底图上划分区域、在区域内记格位和货物、可搜索、可拍照。

---

## 2. 产品目标

### 2.1 目标

1. 上传场地平面图或卫星影像作为底图。底图像素是坐标原点。
2. 在底图上绘制区域多边形。名称自动按 A、B、C… 分配，不要求画完再手填名字。
3. 选中区域后高亮并显示名称，不自动放大。
4. 在区域内点选或框选格位，货物绑定位置，支持照片、状态和移动历史。
5. 在底部「查找」里搜索在场货物，点结果后在当前地图上标出位置。
6. 用「尺寸校准」或「尺寸数据测算」把像素换成米，区域显示外接宽高和面积。
7. 手机可用。在场保留照片；运走后删除该货物的照片。

### 2.2 非目标

- GPS 定位
- TradeWindow 双向联动
- 复杂角色权限（本期登录用户均可编辑）
- 把官方地图控件嵌进应用。官方测距只用来给校准线提供米数
- 底图无限放大仍保持卫星瓦片级清晰。放大超过原图像素后会看到像素块

---

## 3. 用户与界面

登录用户可以绘制区域、记位置与货物、拍照、搜索、移库和运走。账号在 Supabase 后台创建。

底图所在的三个页签共用同一张地图，切换页签不改变地图的显示大小和位置。底部固定一块操作栏，再下面是页签。页签从左到右：

| 页签 | 路径 | 操作栏 |
| :--- | :--- | :--- |
| 查找 | `/search` | 搜索框和结果。没有「新增区域」 |
| 管理 | `/manage` | 底图、区域、格位。面板盖住地图，换页签离开 |
| 区域绘制 | `/` | 「新增区域」、区域芯片、选中后的尺寸和删除 |

`/admin` 转到 `/manage`。货物详情仍走 `/item/:id`。

非绘制、非点选、非框选时，按住左键拖动地图，效果与按住中键相同。滚轮始终以光标为中心缩放，放大上限约为原图的 16 倍，缩小停在整张图可见。

---

## 4. 底图

管理 → 底图，按钮自上而下、等宽排列：

1. **上传平面图**。PNG、WebP、JPEG 在长边不超过 8192 像素且文件不超过 20MB 时保留原文件；否则压成 JPEG，质量 0.92，长边 8192。货物照片仍是最长边 1600、质量 0.8。更换底图后清空米制比例，需要重新做尺寸校准。
2. **尺寸校准**。手填「1 像素 = 多少米」，保存后写入 `sites.meters_per_pixel`。
3. **尺寸数据测算**。在地图上点一条已知长度的地面边（围栏、车道、墙根，不量屋顶）。单击起点、单击终点，两端可拖。笔尖跟随指针，起点和笔尖之间有虚线。中键移动地图，滚轮缩放。填入这条线的实际米数后保存，得到同一字段 `meters_per_pixel`。可重画。
4. **删除平面图**。先点删除，再点一次「确定」才删除。点「取消」则不删。区域和格位保留，米制比例一并清掉。

底图画在地图画布上，按当前视野从原图取样。缩小到比屏幕更密时做平滑，放大到 1 像素对 1 屏幕像素之后用最近邻，避免线条被抹糊。超过原图像素后仍会发块。

数据库需要列 `sites.meters_per_pixel`（`supabase/calibrate_scale.sql`，在 SQL Editor 执行一次）。

## 5. 区域绘制

点「新增区域」后：

- 画笔跟随鼠标。单击增加一个角点。上一个点到笔尖有虚线。
- 已有圆点可以拖动微调。
- 至少三个角。双击、回车，或点回红色起点，闭合并保存。
- 右键撤销上一个点。ESC 取消整次绘制。
- 中键移动地图，滚轮缩放。绘制过程中左键用来落点和拖点，不拖动地图。
- 保存后停在当前视野，不自动缩放到新区域。

名称和代号相同，取已有轮廓里第一个没用过的字母：A、B、C…Z、AA。没有轮廓的空预设区域不占字母。已保存的名称不改。

选中区域：轮廓加亮，名称画在多边形重心。不放大进区域。全图仍显示其他区域。只有选中的区域显示格位。

删除区域：点「删除」后出现「确定」和「取消」，再点「确定」才删除。区域内还有未运走货物时不能删。空格位随区域一起删除。管理列表和区域绘制操作栏都用这套按钮，不用系统弹窗。

区域尺寸（已保存米制比例时）：外接矩形的宽 × 高，以及多边形鞋带面积换算的平方米。显示在管理的区域列表，以及区域绘制页选中区域时的操作栏。

---

## 6. 格位、货物、查找

- 在管理里选中已绘制区域后，可以点选单个格位，或按住拖出矩形批量生成格位。
- 格位颜色：绿有货、灰空、黄待取、红特殊。
- 货物：编号、名称、描述、位置、状态、备注、多张照片。一位置可以有多件货。
- 运走：记下出库，清空位置，删除该货物相关照片。
- 查找只搜未运走货物。点结果后在当前地图上标出对应格位并选中其所在区域，不强制把地图放大到该区域。

尚未实现、仍作为后续项：

- 新格位必须落在所选区域多边形内
- 地图顶部常驻大搜索框，以及搜索后自动放大到区域
- 区域改名、重绘已有轮廓

---

## 7. 数据

- `sites`：底图路径、宽、高（像素）、`meters_per_pixel`
- `areas`：code、name、color、polygon（图像素坐标 `[[x,y],...]`）
- `locations`：code、label、area_id、x、y、status
- `items` / `movements` / `photos`
- Storage：`basemaps`、`photos`

RLS：登录用户可读写业务表。前端只用 publishable/anon key。

---

## 8. 技术约束

- Vite + React + TypeScript。地图是固定底图上的画布和 SVG，不用 Leaflet 拖拽底图
- 坐标、笔画、校准都用图像素，不随缩放改写
- Supabase Sydney。GitHub Pages 托管前端
- 照片在场保留、运走删除，以控制免费 Storage

---

## 9. 验收

1. 三个页签切换时，整张底图的显示范围不变。
2. 新增区域：单击落点，双击或回车闭合，名称自动为下一个字母，闭合后视角不变。
3. 选中区域只高亮并显示名称，不放大。
4. 尺寸校准可以手填米/像素；尺寸数据测算可以用一条已知边算出同一比例；选中区域能看到米和外接尺寸。
5. 删除平面图和删除区域都要再点一次「确定」，没有系统弹窗。
6. 查找能标出在场货物。运走后相关照片删除。
